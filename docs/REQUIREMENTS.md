## 功能与玩法需求

**已确认的交互细节：** 使用独立「砍树」按钮进行手动砍伐（REQ-0007）；**按住按钮可以连续砍伐（REQ-0008）**；不将直接点击树木作为默认触发方式。建议松开按钮即停止连砍、短按触发单次砍伐，但这两条的行为细节及连砍频率仍待设计评审。用户初步倾向整体「偏手动点击」（[IDEA-0001](./IDEAS_INBOX.md)），但尚未确认完整玩法。**砍树速度与斧头升级分为两个独立设计维度（REQ-0009）**，不默认升级斧头就提高砍树速度。**斧头升级主要增加单次伤害及 N×N 方格内同时受伤的树木覆盖范围；该区域以当前砍伐目标树木所在格为中心（REQ-0010）**。在可移动角色的场景里，如何根据人物位置/朝向决定该目标仍待确认（见 REQ-0012），并不等于玩家必须点选树木。**炸弹是与树木不同的消耗性可放置物品，放置后爆炸并造成一次性范围伤害；同级比较覆盖范围大于斧头（REQ-0011）**。具体范围格数、爆炸时机、威力、消耗与升级数值、速度单位和获取/升级方式、树木生命值、木材收益、其他数值规则与美术规格等仍为 [V0.1 设计草案](./GAME_DESIGN_DRAFT.md)中的待讨论建议，**不构成开发授权**。

**重要玩法修正（REQ-0012）：** 游戏不是静态界面的站桩点击砍树。玩家在 2D 地图中实际操纵人物移动，走到树木附近，人物执行挥斧砍伐动作；方格范围用于计算角色当次砍伐能影响的树木，而非把地图当成只需点击选树的棋盘。**已确定手机用虚拟摇杆移动+独立砍树按钮（REQ-0013）；电脑通过 WASD 四方向键移动+鼠标右键点击砍树（REQ-0014）**。可砍距离、方向判定、目标确定、动画、移动中能否挥斧、电脑右键长按行为仍待评审，不得自动定为正式规则。
