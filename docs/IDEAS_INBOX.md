# ChopTree · 待确认想法收集箱

前置：[WORKFLOW.md](./WORKFLOW.md)（尤其是“主动判断是否要记录”）。

## 用途

防止用户讨论中提出的可能重要内容因未当场说「记下来」而丢失。这里是**候选想法 / 有疑义的信息**，不是正式需求清单，也不代表用户已批准开发。

建议 ID 为 `IDEA-0001` 等；状态用「待确认 / 已确认并迁移 / 已否决 / 暂缓」。
只记录可跨对话复用的信息，避免长篇聊天逐字转储；如有重要前提或不确定性，务必注明。

## 处理约束

- AI 主动识别与捕获有价值候选，无需用户提醒；候选不等于实施许可。
- 若影响后续实现，尽早询问用户是否确定；得到明确答复后，将结论写入 [REQUIREMENTS.md](./REQUIREMENTS.md) 或 [DECISIONS.md](./DECISIONS.md)，并在此保留迁移状态。
- 不要把 AI 提议当成用户确认的玩法；当前仅有「偏手动点击」的初步方向，仍未正式确认完整玩法。
- 不能存储凭证、密钥及未经允许的敏感数据。
- 最终更新项目状态：[PROJECT_STATUS.md](./PROJECT_STATUS.md)。
