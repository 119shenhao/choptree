# ChopTree · 游戏设计草案 V0.1（讨论稿）

> 2026-11-21 建立。**状态：待讨论 / 未批准实施。** 这是一份先设计、后确认、再开发的讨论稿，不代表用户批准其中具体玩法或美术方案；本阶段禁止直接编写游戏代码。
>
> **信息来源区分：** 用户表示游戏「应该是偏手动点击的」，要求「先别直接开始写，先设计、记录」，随后明确选择使用**独立的「砍树」操作按钮**（[REQ-0007](./REQUIREMENTS.md)）。其余机制、界面与数值均为 AI 供讨论的建议。关联 [IDEA-0001 / IDEA-0002](./IDEAS_INBOX.md)、[REQ-0006](./REQUIREMENTS.md)。

## 一、设计目标

- 平台已确认：纯 HTML5 小游戏。
- 操作方向：用户倾向**以手动点击砍树为主**；具体触发方式已确认采用**独立的「砍树」按钮**（REQ-0007），而非直接点击树木。是否在未来加入自动玩法仍未定。
- V0.1 目标（建议）：用极小的可玩循环测试「点击反馈是否爽快」「资源增长与升级是否有动力」，暂不追求复杂内容。
- 本阶段产出：确定玩法方向、界面结构和第一版边界的讨论稿；**不创建游戏代码、不部署**。

## 二、核心循环（建议，未确认）

1. 玩家按下画面上的独立 **「砍树」按钮**触发一次手动砍伐（**输入方式已确认**；是否按住连续砍伐、是否有冷却等仍待讨论）。
2. 树木减少生命值或累积砍伐进度，给出明显反馈（晃动、木屑、数字或音效，可选）。
3. 砍倒后获得木材，自动出现下一棵树，减少重复操作。
4. 消耗木材升级斧头，使后续每次点击更有效率。
5. 重复以上过程。是否解锁树种/区域、如何解锁，由后续设计讨论决定。

这里的「木材」「斧头升级」「树木生命值」都是**方案提议**，不是已经确认的功能。

## 三、建议的竖屏手机主界面（未确认）

```text
┌─────────────────────────────┐
│   木材：120    斧头 Lv. 2  │
│        （资源与当前能力）    │
│                             │
│         树木生命值          │
│        ███████░░░           │
│                             │
│            🌳               │
│       （树木视觉展示）      │
│                             │
│          [砍树]             │
│    [升级斧头：花费木材]     │
│                             │
│  设置 / 音效等辅助入口      │
└─────────────────────────────┘
```

- **已确认的交互：** 使用独立「砍树」按钮，树木用于展示砍伐对象和动画；**不以点击树木本体作为砍伐输入**。草图中按钮位置只是布局建议，尚未获确认。
- **设计建议：** 树木为主视觉；资源与升级信息始终易读；主要操作区域对手机单手触控友好。
- **还未决定：** 竖屏还是横屏、卡通还是像素风、是否显示人物、按钮具体位置及尺寸。
- 以上「120」「Lv. 2」仅为示意文本，不是数值承诺。

## 四、第一版功能范围候选（未确认）

**建议纳入最小原型：**
- 通过单独的「砍树」按钮触发手动砍伐（**已确认输入方式**）；即时视觉反馈为待确认的设计建议。
- 一种基础树木和简单的砍倒/重生循环。
- 木材资源累计与消耗。
- 一项斧头升级入口，以及点击效率变化。
- 基础本地存档（例如浏览器刷新后保留进度）。
- 可在手机浏览器顺畅操作的布局。

**建议暂缓：** 工人自动砍树、离线收益、任务/成就、多人、排行榜、登录、支付、广告、复杂地图、云端存档。暂缓不等于永远不做。

## 五、数值和成长的设计思路（全部待讨论）

- 砍伐体验：每次有效点击推进进度；避免频繁无反馈点击。
- 成长体验：砍树获得资源，升级后同等点击量可完成更难的树。
- 节奏目标：开局快速获得一次「砍倒—奖励—升级」体验，再逐渐增加目标。
- **暂不确定具体数值：** 初始伤害、生命值、木材收益、升级价格、解锁门槛等，在玩法认可后再列出可调整的数值表。

## 六、待确认的核心问题

1. **核心交互已确定：** 使用独立的「砍树」按钮（REQ-0007）。**仍待讨论：** 只支持单次点击，还是允许长按、连击等附加机制？
2. **画面表现：** 竖屏/横屏、卡通/像素等方向。
3. **成长主线：** 只升级斧头，还是加人物、工具耐久、树种/场景解锁？
4. **节奏深度：** 纯主动点击；或未来加入少量辅助技能（不等同自动挂机）。
